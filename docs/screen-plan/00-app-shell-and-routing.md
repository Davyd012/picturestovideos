# App Shell And Routing

## Start Here

Build this first.

## Why

The repo navigation guide expects centralized routes and a `ScreenFactory`.

This gives us:

* one place for route names
* one place for route wiring
* a stable path for future typed navigation

## Files

* `lib/app.dart`
* `lib/commons/navigation/app_routes.dart`
* `lib/commons/navigation/app_route_args.dart`
* `lib/commons/navigation/app_navigator.dart`
* `lib/commons/navigation/screen_factory.dart`

## Initial Route

Start on:

* `/audio/import`

## Notes

Use import audio as the entry route until a dedicated home/dashboard exists.
